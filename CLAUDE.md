## Agent skills

### Issue tracker

GitHub Issues via `gh` CLI. External PRs are also a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Prefixed vocabulary: `state:*` (the 5 triage roles), `type:*`, `priority:p0-p3`, `severity:*`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context (monorepo): `CONTEXT-MAP.md` at root, one `CONTEXT.md` per context. See `docs/agents/domain.md`.
