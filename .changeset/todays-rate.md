Today's rate and display currency: Home can show foreign-currency spending "at today's rate"
beside "as recorded", with how much higher or lower the same spending would be, and names any
currency with no rate instead of guessing. An optional display currency (per device) shows the
totals in a second currency, labelled as a view that never changes stored data.
