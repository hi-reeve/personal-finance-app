Home Summary view: a headline comparing the month with the one before, income, spending and net
cards, a daily spending chart and the top Categories. Every chart has a text summary and a table
alternative, amounts hide with one tap, and a month selector changes everything together. Charts
are drawn as plain SVG, so no charts library is added to the bundle. Core gains month helpers and
daily totals under the same counting rules as the by-Category report.
